## 1. Executive Overview

The **Evidence Processing Engine** provides event ingestion, structured persistence, and causal relationship mining for all runtime behavioral telemetry generated by Frida hooks, `mitmproxy` network captures, UI exploration, and logcat logs.

---

## 2. Runtime Event Bus (`event_bus.py`)

The `RuntimeEventBus` ([`event_bus.py`](file:///d:/Projects/Sudarshan%20BOI/shared/sudarshan_core/engines/event_bus.py)) acts as an in-memory publish-subscribe broker for real-time sandbox events:

```python
class RuntimeEventBus:
    def subscribe(self, callback: Callable[[Dict[str, Any]], None]) -> None: ...
    def publish(self, category: str, data: Dict[str, Any]) -> None: ...
```

Event categories include: `frida_hook`, `network`, `ui_action`, `logcat`, and `canary`.

## 4. Fraud Workflow Reconstructor (`workflow_reconstructor.py`)

The `WorkflowReconstructor` ([`workflow_reconstructor.py`](file:///d:/Projects/Sudarshan%20BOI/shared/sudarshan_core/engines/workflow_reconstructor.py)) processes raw evidence records to construct causal temporal chains representing higher-level fraud campaigns:

```mermaid
graph LR
    EV[Raw Evidence Records] --> WE[Workflow Engine]

    WE -->|Step 1: Temporal Sort| SORT[Sorted Timestamp Timeline]
    SORT -->|Step 2: Sequence Pattern Match| MATCH[Fraud Sequence Patterns]
    MATCH -->|Step 3: Causal Precedence Check| CAUSAL[Causal Chain Verification]
    CAUSAL -->|Step 4: Output Contract| WF[FraudWorkflow Model]
```

### Supported Fraud Sequences
- **`FULL_ACCOUNT_TAKEOVER`**: Accessibility Service Active $\rightarrow$ Overlay Phishing Prompt $\rightarrow$ SMS Intercept $\rightarrow$ Network C2 POST.
- **`OTP_THEFT_CHAIN`**: SMS Read/Intercept $\rightarrow$ Network Exfiltration.
- **`OVERLAY_PHISHING_CHAIN`**: Banking Activity Detection $\rightarrow$ Overlay Window Display.
- **`DROPPER_CHAIN`**: Dynamic Code Load (`DexClassLoader`) $\rightarrow$ Network Payload Retrieval.

## 5. Causal Sequence Mapping & MITRE ATT&CK Stages

Reconstructed stages map directly to MITRE ATT&CK for Mobile:

| Sequence Stage | MITRE Technique ID | Description |
| :--- | :--- | :--- |
| **Accessibility Abuse** | `T1628` | Scraping UI fields and intercepting input events. |
| **Overlay Phishing** | `T1637` | Drawing transparent overlays over target banking apps. |
| **SMS Interception** | `T1643` | Intercepting incoming SMS messages containing OTPs. |
| **Dynamic Payload Loading** | `T1407` | Loading secondary un-encrypted DEX files at runtime. |
| **C2 Communication** | `T1437` | Sending stolen credentials to command & control servers. |
