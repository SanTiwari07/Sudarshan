## 1. Transparent Proxying via mitmproxy

To capture all outbound HTTP/HTTPS communications generated by suspected malware, SUDARSHAN deploys a `mitmproxy` sidecar container:

- **Host Binding:** `127.0.0.1:8085` (Loopback only — never exposed on public interfaces).
- **Container Port:** `8080`.
- **Operating Mode:** Transparent interception with automatic SSL certificate authority (CA) pre-installed into the Android guest sandbox.
- **Output:** Writes raw network flows directly to a shared Docker volume (`mitmproxy_har:/har/dump.har`).

---

## 2. Ingestion & Indicator Extraction

`NetworkCapture.ingest_mitmproxy_har()` parses the captured HAR stream:
1. **Domain Extraction:** Extracts fully qualified domain names (FQDNs) and IP endpoints.
2. **C2 Payload Inspection:** Scans POST bodies for exfiltrated SMS messages, contact lists, and device identifiers (IMEI/IMSI).
3. **Correlation Feed:** Transmits newly observed domains directly to the Threat Correlator for real-time reputation scoring.
