# SUDARSHAN — Indicator of Compromise (IOC) Pipeline

> **Classification:** AUTHORITATIVE  

---

Extracts, enriches, and exports actionable forensic indicators:
- **File Hashes:** MD5, SHA-1, SHA-256.
- **Network IOCs:** C2 domains, direct IP addresses, and HTTP POST URLs.
- **Application Identifiers:** Malicious package names and counterfeit developer certificate SHA-256 fingerprints.
