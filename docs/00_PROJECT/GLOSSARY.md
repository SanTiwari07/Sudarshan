# SUDARSHAN — Domain & Technical Glossary

> **Classification:** SUPPORTING / REFERENCE  

---

| Term | Full Name / Expansion | Definition in SUDARSHAN |
| :--- | :--- | :--- |
| **FRS** | Fraud Risk Score | Authoritative composite risk score (0–100) calculated deterministically: $0.25 \times \text{STEI} + 0.35 \times \text{BFCI} + 0.20 \times \text{Correlation} + 0.20 \times \text{BankingImpact}$. |
| **STEI** | Static Threat Evaluation Index | 5-axis static analysis score: $0.60 \times \text{CT} + 0.20 \times \text{BT} + 0.10 \times \text{PR} + 0.05 \times \text{OB} + 0.05 \times \text{IR}$. |
| **BFCI** | Behavioral Fraud Confidence Index | 7-axis dynamic Frida behavioral index tracking accessibility, SMS, overlay, banking targeting, code execution, network, and persistence. |
| **VIDE** | Visual Impersonation Detection Engine | Subsystem analyzing layout AST trees, CIEDE2000 color palettes, fuzzy text matching, and signing certificates to identify counterfeit banking apps. |
| **ATS** | Automated Transfer System | Malware mechanism using Android Accessibility APIs to automatically navigate banking apps, fill transfer fields, and bypass confirmation prompts without victim consent. |
| **C2** | Command and Control | Attacker-controlled infrastructure used to deliver secondary payloads, receive exfiltrated credentials, and command trojanized devices. |
| **CH27 Triad** | Chapter 27 Fraud Triad Escalation | Deterministic escalation rule triggering FRS >= 95 Critical when an APK exhibits High Visual Clone Confidence (>0.85) + Signer Mismatch + Accessibility Abuse. |
| **HAR** | HTTP Archive format | Network traffic archive captured transparently via the mitmproxy sidecar during dynamic sandbox execution. |
| **RAG** | Retrieval-Augmented Generation | AI investigation pipeline extracting indexed factual evidence chunks into Gemini context prompts without exposing raw APK data. |
| **STIX 2.1** | Structured Threat Information Expression | Standardized threat intelligence serialization format generated by SUDARSHAN for automated SIEM/SOAR ingestion. |
